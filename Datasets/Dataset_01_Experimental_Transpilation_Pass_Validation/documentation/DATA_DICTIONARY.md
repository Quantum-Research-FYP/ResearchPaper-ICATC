# Dataset 01: Data Dictionary

## 1. `pass_execution_register_347_slots.csv`
Primary execution register containing 347 individual pass transformation runs.

| Column Name | Data Type | Description | Example Value |
|:---|:---|:---|:---|
| `record_id` | String | Unique primary identifier for the pass transformation run | `PV001` to `PV347` |
| `circuit_id` | String | Identifier of the benchmark circuit compiled | `T01` to `T30` |
| `pass_id` | String | Unique compiler pass identifier | `PASS_BASISTRANSLATOR` |
| `pass_name` | String | Canonical pass class name in Qiskit transpiler | `BasisTranslator` |
| `execution_index` | Integer | 1-based order in which the pass ran during transpilation | `1` to `37` |
| `timestamp_utc` | ISO 8601 | UTC timestamp of the execution | `2026-11-18T10:15:00Z` |
| `compiler_name` | String | Compiler system used | `Qiskit` |
| `compiler_version` | String | Exact version of the compiler | `1.4.6` |
| `backend_or_target` | String | Target configuration identifier | `linear_6`, `h_shape_7` |
| `target_basis_gates` | String | Native basis gate set of the target | `cz,sx,rz,x,id` |
| `target_topology` | String | Connectivity graph description | `Linear chain (6 qubits)` |
| `before_snapshot_file` | Relative Path | Relative path to OpenQASM 3 snapshot before pass execution | `data/circuit_snapshots/before/PV001_before.qasm` |
| `after_snapshot_file` | Relative Path | Relative path to OpenQASM 3 snapshot after pass execution | `data/circuit_snapshots/after/PV001_after.qasm` |
| `before_gate_count` | Integer | Total gate count before pass ran | `2` |
| `after_gate_count` | Integer | Total gate count after pass ran | `4` |
| `before_depth` | Integer | Circuit depth before pass ran | `1` |
| `after_depth` | Integer | Circuit depth after pass ran | `3` |
| `before_layout` | String | Qubit layout configuration before pass | `trivial`, `virtual_mapped` |
| `after_layout` | String | Qubit layout configuration after pass | `virtual_mapped`, `physical_active` |
| `actual_transformation` | String | Objective diff summary of gates and depth changed | `Circuit transformed: +2 gates, +2 depth (sx: +2)` |
| `generated_explanation_id` | String | Identifier linking to the explanation record | `EXP_PV001` |
| `generated_explanation_text` | String | Full text explanation generated by Quantum Studio engine | `Purpose: Decomposes non-native gates...` |
| `raw_trace_file` | Relative Path | Relative path to JSON trace with DAG metrics and timing | `data/raw_pass_traces/PV001_trace.json` |
| `source_hash` | String | 16-character SHA256 checksum of circuit and execution context | `a1b2c3d4e5f6...` |
| `record_provenance` | String | Execution provenance flag | `ACTUAL_TRANSFORMATION_EXECUTION` |
| `record_status` | String | Audit verification status | `READY_FOR_REVIEW` |
| `missing_evidence_notes` | String | Audit error or completeness notes (empty when complete) | *(empty string)* |

## 2. `evaluator_1_labels_template.csv` & `evaluator_2_labels_template.csv`
Blinded independent evaluation records filled by expert evaluators.

| Column Name | Data Type | Description | Values |
|:---|:---|:---|:---|
| `record_id` | String | Record ID matching pass execution register | `PV001` to `PV347` |
| `explanation_id` | String | Explanation identifier | `EXP_PV001` to `EXP_PV347` |
| `evaluator_id` | String | Anonymized evaluator identifier | `EVAL_01`, `EVAL_02` |
| `evaluator_expertise` | String | Professional qualification and specialization | Senior Quantum Researcher / Systems Engineer |
| `blind_review` | Boolean | Whether evaluator was blinded to engine correctness and peer scores | `TRUE` |
| `transformation_identified` | Boolean | Whether the explanation identified the true structural change | `TRUE`, `FALSE` |
| `reasoning_accurate` | Boolean | Whether the causal rationale given is technically accurate | `TRUE`, `FALSE` |
| `label` | Categorical | Independent categorical rating | `Correct`, `Partially correct`, `Incorrect` |
| `confidence_1_to_5` | Integer | Evaluator confidence rating | `1` (lowest) to `5` (highest) |
| `evidence_comment` | String | Evaluator justification citing DAG diffs and gate operations | Text string |
| `evaluation_timestamp_utc` | ISO 8601 | UTC timestamp when evaluation was logged | `2026-11-18T14:30:00Z` |
| `rubric_version` | String | Version of the evaluation rubric applied | `v1.0` |
| `independent_before_adjudication` | Boolean | Confirmation that label was frozen before adjudication | `TRUE` |

---

## 3. `adjudication/adjudication_template.csv`
Consensus adjudication records for any evaluator disagreements.

| Column Name | Data Type | Description |
|:---|:---|:---|
| `record_id` | String | Record ID (`PV001` to `PV347`) |
| `evaluator_1_label` | Categorical | Pre-adjudication rating from Evaluator 1 |
| `evaluator_2_label` | Categorical | Pre-adjudication rating from Evaluator 2 |
| `disagreement` | Boolean | `TRUE` if Evaluator 1 and Evaluator 2 differed; `FALSE` otherwise |
| `adjudicator_id` | String | Identifier of senior adjudicator (`ADJUDICATOR_01`) |
| `final_label` | Categorical | Consensus rating: `Correct`, `Partially correct`, `Incorrect` |
| `adjudication_reason` | String | Detailed technical basis citing evaluation rubric |
| `adjudication_timestamp_utc` | ISO 8601 | UTC timestamp of final consensus resolution |
| `rubric_version` | String | Rubric version applied (`v1.0`) |
